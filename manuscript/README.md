# Hospital air and surface microbiome — manuscript analysis

Project-specific scripts and processed datasets for the manuscript *Hospital air and surface microbiome* (submitted to *Microbiome*). The general analysis pipeline is [meridian](https://github.com/Julio92-C/meridian). This folder holds only what is specific to this study. Raw reads are in NCBI BioProject PRJNA1402132.

## Layout

| Path | Content |
|---|---|
| `scripts/config.yaml` | meridian configuration for this study (NX subtraction, microbial-only taxa, >10-read floor, ALDEx2 settings) |
| `scripts/prep_inputs.R` | Builds pipeline-ready inputs (combined Kraken2 report, Bracken-shaped table, metadata with controls) from the upstream files |
| `scripts/polish_*.R` | Manuscript figures and tables built from the pipeline outputs: Figure 1 (`polish_taxa_overview.R`), Figure 2 and Figure S3 (`polish_relative_abundance.R`), Figure 4 chord (`polish_chord.R`), Figure S2 (`polish_alpha_panel.R`), Figure S4 (`polish_beta_venn.R`), Figure S5 (`polish_ge_heatmap.R`), Table 1 (`polish_table1.R`) |
| `data/metadata/hospital_metadata.csv` | Sample metadata (type, ward, location), including negative controls |
| `data/processed/taxa_counts_floor10.csv.gz` | Taxon counts per sample after NX subtraction and removal of non-microbial reads, keeping only entries with more than 10 reads (long format) |
| `data/processed/abri_kraken2_cleaned.csv` | Element-carrying reads: ABRicate hits (CARD, VFDB, PlasmidFinder) linked to their Kraken2 taxon |
| `data/processed/genetable_normdata.csv` | TPM-normalised gene table |
| `data/processed/alpha_diversity.csv`, `beta_diversity_*.csv` | Community diversity per sample, ordination coordinates and adjusted p-values |
| `data/processed/aldex2/` | ALDEx2 results for species and genes (Table S2) |
| `data/processed/resistome/`, `virulome/`, `mobilome/`, `stats/` | Genetic-element diversity and test results |
| `data/processed/network/` | Network node/edge files for Gephi (Figure 5), chord links and topology |

## Reproducing

1. Clone meridian and check out the version used for the manuscript (branch `fix/hospital-species-aldex2`, commit `0a226ff`; to be replaced by a release tag).
2. Edit `project_root` in `scripts/config.yaml` to the folder holding the upstream reports and metadata.
3. Run `Rscript scripts/prep_inputs.R`, then the meridian pipeline with `scripts/config.yaml`.
4. Run the `polish_*.R` scripts from the meridian checkout. Set `MERIDIAN_HOME` to that checkout; `polish_relative_abundance.R` uses meridian's `R/utils_taxa.R`.

The full pre-floor taxon table (~190 MB) is not stored here; it is regenerated by the pipeline.
